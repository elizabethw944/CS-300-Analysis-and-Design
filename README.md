In the projects for this course, the problem I was solving was creating a program that would read course data from a file, then organize it so that it would be easy to search and display the information. The goal was to help academic advisors find course information quickly, including prerequisites, and display all of the courses in sorted order. To approach this problem, I decided to focus on using the Binary Search Tree for my main data structure. I chose this data structure because it allows data to be stored in a sorted order and makes search more efficient compared to other data structures. Understanding data structures was important to this project because it helped me see how different ways of organizing data can impact performance and how programs can retrieve data. 
While working through this project, I did run into a few challenges, especially when dealing with file input, parsing the CSV file, and making sure the data was stored correctly. Another challenge was making sure the data was read correctly and handling cases where the file format might not be valid. I also had to make sure the prerequisites were being handled appropriately and displayed with their course titles. I overcame these issues by working through and testing my code step by step, making sure to fix any small mistakes, then going back to my pseudocode to make sure my logic was right. Reviewing my pseudocode also helped me to stay organized and fix problems more effectively. Breaking down the problem into smaller parts and working through them one step at a time helped make everything much more manageable. 
This project really helped me expand my approach to software design by showing me how important planning is before writing code. Creating the pseudocode helped make it easier to see what needed to be done and helped guide my implementation. I also learned why it is important to keep code organized by separating tasks into different functions, which also makes the program easier to follow and debug. Additionally, this project helped me improve how I write programs that are more readable and maintainable. I also gained a better understanding of how to make use of different data structures in real world situations.
